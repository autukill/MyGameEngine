# 2026-08-08

## 动画就绪 Sprite API

- `SpriteRef` 已从纹理句柄/尺寸/UV 容器改为稳定逻辑名称；GPU 帧通过 `ISpriteResolver` 解析。
- Core 新增 `SpriteMetadata`、`ResolvedSpriteFrame`、`SpriteDrawCommand`、`SpriteGeometry` 与 `batch.DrawSprite/DrawSpriteExt/DrawSpriteStretched`。
- `GameInstance` 新增 `ImageIndex`、`ImageSpeed`、`DrawSelf`；Scene 在 End Step 后按 Sprite FPS 推进并循环动画。
- 新增独立 `Engine.Features.Sprites`、`Sprites.Tests`、`Sprites.VisualTests`，解决方案共 18 个项目。
- `SpriteLibrary` 支持单帧、任意 UV 和行优先 Grid 注册；纹理句柄为外部借用，不负责释放。
- Runner 使用 `runner.orbiting` 逻辑 Sprite 和中心原点；Stencil 内部 Batch 共享 Sprite resolver。
- 后续边界：自动 Atlas、Nine Slice 与碰撞 Mask 不属于本阶段。

## Texture Assets 垂直切片

- 新增 `TextureRef`/`ITextureResolver`、`TextureLibrary`与可替换 `ITextureBackend`；纹理句柄由资产库统一拥有与释放。
- SkiaSharp 默认解码器输出非预乘 RGBA8，支持 PNG 与静态 WebP，并对解码尺寸设置上限。
- JSON 纹理清单支持 Smooth/PixelArt 采样预设、content-root 路径约束和批量失败回滚。
- SpriteLibrary 改为注册 `TextureRef`；Runner 与 Sprites.VisualTests 不再手写 OpenGL 纹理上传。
- 解决方案共 20 个项目；新增 TextureAssets 无窗口测试，图形上传复用 Sprites.VisualTests 验证。

## 声明式 Content Assets 与多图片帧

- 新增 `Engine.Features.ContentAssets` 与 `ContentAssets.Tests`，解决方案增至 22 个项目、8 个无窗口冒烟入口。
- 单一严格版本化 `assets.json` 同时声明 Texture、Sprite 与包依赖；Manager 在 packagesRoot 内解析拓扑并同步装配。
- `SpriteFrameSource(TextureRef, PixelRectI)` 与 `RegisterPixelFrames` 允许同一 Sprite 的每帧来自不同图片并带像素裁剪。
- 包缓存采用外部租约 + 依赖持有引用计数；失败只回滚本次新增资源，卸载顺序为 Sprite → Texture → 依赖。
- Runner 与 Sprites.VisualTests 均迁移到自己的资产包；VisualTests 保留 WebP Grid，并新增两张独立 WebP 的 Frames 动画。
- Atlas 稳定边界：后续构建器消费规范化逐帧来源，可跨页重映射；放不下的大帧保持独立 TextureRef。

## 离线 Texture Atlas 与 AssetCompiler

- 新增无 OpenGL 依赖的 `Engine.Features.TextureAtlas` 与测试：确定性 Shelf、多页、padding、edge extrude、页面裁切和大帧旁路。
- `assets.json` 顶层可选 `atlas` 策略，显式列出构建输入 Texture；直接运行源包时仍可回退到原图加载。
- 新增 `Engine.Tools.AssetCompiler` 与测试，输出标准运行时 assets.json、无损 PNG Atlas 页面和依赖包目录。
- 编译器按 PixelArt/Smooth 分组；一个 Sprite 可跨 Atlas 页，也可混合 Atlas 与独立大帧。
- Sprites.VisualTests 已切换到真实编译产物：3 张 WebP 源 Texture 归并为 1 张 Atlas PNG，白纹理保持独立。
- 解决方案增至 26 个项目、102 个 C# 文件、10 个无窗口冒烟入口。
