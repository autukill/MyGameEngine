# 2026-08-08

## 动画就绪 Sprite API

- `SpriteRef` 已从纹理句柄/尺寸/UV 容器改为稳定逻辑名称；GPU 帧通过 `ISpriteResolver` 解析。
- Core 新增 `SpriteMetadata`、`ResolvedSpriteFrame`、`SpriteDrawCommand`、`SpriteGeometry` 与 `batch.DrawSprite/DrawSpriteExt/DrawSpriteStretched`。
- `GameInstance` 新增 `ImageIndex`、`ImageSpeed`、`DrawSelf`；Scene 在 End Step 后按 Sprite FPS 推进并循环动画。
- 新增独立 `Engine.Features.Sprites`、`Sprites.Tests`、`Sprites.VisualTests`，解决方案共 18 个项目。
- `SpriteLibrary` 支持单帧、任意 UV 和行优先 Grid 注册；纹理句柄为外部借用，不负责释放。
- Runner 使用 `runner.orbiting` 逻辑 Sprite 和中心原点；Stencil 内部 Batch 共享 Sprite resolver。
- 后续边界：自动 Atlas、Nine Slice 与碰撞 Mask 不属于本阶段。

## Texture Assets 垂直切片

- 新增 `TextureRef`/`ITextureResolver`、`TextureLibrary`与可替换 `ITextureBackend`；纹理句柄由资产库统一拥有与释放。
- SkiaSharp 默认解码器输出非预乘 RGBA8，支持 PNG 与静态 WebP，并对解码尺寸设置上限。
- JSON 纹理清单支持 Smooth/PixelArt 采样预设、content-root 路径约束和批量失败回滚。
- SpriteLibrary 改为注册 `TextureRef`；Runner 与 Sprites.VisualTests 不再手写 OpenGL 纹理上传。
- 解决方案共 20 个项目；新增 TextureAssets 无窗口测试，图形上传复用 Sprites.VisualTests 验证。
