## 任务 2：Scene 系统重新设计（Phase 1.4）

用户要求规划设计 Scene 系统（对标 GMS Room），具备管理 **Viewport、GameInstance、Layer、Background、Hook** 的能力。

### 变更摘要
1. **新增 Domain 值对象**：
   - `SceneLayerConfig`（readonly record struct）：Name + DepthOrder + IsVisible
   - `BackgroundConfig`（readonly record struct）：ClearColor + BackgroundSprite + TileMode（None/Stretch/Tile）

2. **新增领域事件**（`SceneEvents.cs`）：
   - `SceneStartedEvent` / `SceneEndedEvent` / `LayerAddedEvent` / `LayerVisibilityChangedEvent`

3. **重构 SceneAggregate**（核心）：
   - 新增 `ViewportWidth/ViewportHeight`
   - 新增 `Background` 属性
   - 新增 Layer 配置管理（AddLayer/RemoveLayer/SetLayerVisible/FindLayerConfig）
   - 新增 Scene 级 Hook（OnStart/OnEnd/OnBeforeStep/OnAfterStep）
   - `DrawActive()` 现按 Layer 分组遍历（IsVisible 过滤 + 每层内 Depth 排序）
   - 新增 `DrawActive(batch, layerName)` 重载（单 Layer 渲染）
   - 新增 Scene 生命周期：`Start()` / `End()`
   - 构造函数自动创建 3 个默认 Layer：Background(10000) / Instances(0) / UI(-10000)

4. **GameInstance 扩展**：
   - 新增 `LayerName` 属性（默认 null，加入 Scene 时自动补填 "Instances"）

5. **Command/Handler 扩展**：
   - 新增 `AddLayerCommand` / `SetLayerVisibleCommand` / `SetBackgroundCommand`
   - `SceneCommandHandlers` 新增对应 Handler

6. **SceneRenderPass 适配**：
   - 新增 `GL gl` 构造参数（用于 Background clear）
   - Execute() 现从 scene.Background 读取清屏色执行 glClear
   - 支持 Background 精灵（Stretch/Tile）

7. **SceneRenderContext 标记 [Obsolete]**：不再使用，Layer/Camera 管理已合并到 SceneAggregate

8. **更新 Runner & Tests**：`Program.cs` 改用新的 SceneAggregate API，`DddTests` 覆盖所有新功能

## 任务 3：Engine.Features 拆分为独立 module project

用户要求把 `Engine.Features` 从单一 csproj 改造成"每个 Feature 一个独立 module project + 每个 Feature 一个测试目录（含冒烟测试 + 可运行看效果 Demo）"。

### 变更摘要
1. **删除** `src/Engine.Features/Engine.Features.csproj`（含根目录 bin/obj 残留，未删除由用户拒批——不影响编译）
2. **新增 4 个 Feature module project**（均引用 `..\..\Engine.Core\Engine.Core.csproj`）：
   - `Camera/Camera.csproj`：无 Silk.NET 依赖，仅 Engine.Core（最底层）
   - `RenderPipeline/RenderPipeline.csproj`：+ Silk.NET.OpenGL + Camera
   - `SceneSystem/SceneSystem.csproj`：+ Camera + RenderPipeline
   - `StencilMasking/StencilMasking.csproj`：+ Silk.NET.OpenGL + Camera + RenderPipeline
3. **新增 4 个冒烟测试项目**（可运行 Program，无 GL 依赖，命名 `Xxx.Tests.csproj`）：
   - `Camera.Tests/`、`RenderPipeline.Tests/`、`SceneSystem.Tests/`、`StencilMasking.Tests/`
   - 测纯逻辑值对象/矩阵/命令链路/图层排序
4. **新增 4 个图形看效果项目**（可运行 Demo，命名 `Xxx.VisualTests.csproj`，需 OpenGL 窗口）：
   - `Camera.VisualTests/`（WASD 平移/QE 缩放/R 震屏）
   - `RenderPipeline.VisualTests/`（Scene+Bloom+Compositor 多 Pass，含 PIP 分屏）
   - `SceneSystem.VisualTests/`（多 Layer 分层渲染 + 空格/B 切换层可见性）
   - `StencilMasking.VisualTests/`（聚光灯 Stencil 遮罩 + M 切换内/外）
5. **更新引用**：`MyGame.Runner.csproj`、`Engine.DddTests.csproj` 改为引用独立 Feature 项目；`MyGameEngine.slnx` 纳入全部 16 个项目
6. **顺手修复两处引擎 bug**：
   - `StencilMaskState.Default` 原本 `new()` 对值类型等价 default（ref=0/mask=0），修正为显式 `(ref:1, mask:0xFF, ShowInside)` 以符合注释语义
   - `ViewportRect` 新增 `TopLeftQuarter` 预设

### 关键架构事实（已验证）
- 依赖图无循环，单向：`Camera`（底）← `RenderPipeline` ← `SceneSystem`/`StencilMasking`
- 命名空间保持 `GameEngine.Features.Xxx.*`，所有引用方 using 零改动，只改 csproj
- `ISpriteBatch.Draw(uint, Vector2, Vector2, Vector4, Vector4)` 的 uvBounds 参数是**必需**（无默认值）
- `SceneLayerConfig` 是 `readonly record struct`，`FindLayerConfig` 返回 nullable，访问字段需 `cfg.Value.xxx`
- 编译结果：16 项目全部成功，0 警告 0 错误；4 个冒烟测试 + Engine.DddTests 全部通过
- 图形 VisualTests 项目已编译通过（无头环境无法运行，需用户在有 GL 环境手动 `dotnet run` 查看效果）
