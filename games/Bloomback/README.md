# 《驮春 / Bloomback》概念档案

> 状态：概念阶段，尚未立项开发。

《驮春 / Bloomback》是 MyGameEngine 的一个未来真实游戏候选：玩家在最后一只迁徙巨兽背上种植一座会自行战斗的花园，利用植物邻接与生态连锁，护送巨兽穿过约 15 分钟的永夜。

这个目录目前只保存创意和技术判断，不代表游戏已经进入制作：

- 没有游戏项目、可执行程序或解决方案引用。
- 没有正式 Sprite、音频、字体或 Content Package。
- 没有已经承诺的发布日期与目标平台列表。
- 不改变 MyGameEngine 当前开发优先级。
