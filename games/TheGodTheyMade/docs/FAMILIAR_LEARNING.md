# 神兽学习系统

## 核心承诺

神兽不是换皮单位，也不是玩家完全遥控的英雄。玩家教会它习惯，它再用自己的性格和当前身体解释这些习惯。

首版只验证猿形身体，其他身体在核心学习体验成立后再加入。

## 精神、身体与记忆

神兽由三层状态组成：

- **精神性格**：好奇、谨慎、共情和自主倾向；更换身体后保留。
- **学习记忆**：上下文—行动倾向及其支持、制止历史；更换身体后尽量保留。
- **身体能力**：当前身体能够感知和执行的动作，例如猿能搬运、敲击和浇水，鹤可能飞越障碍但不能搬巨石。

未来换体不是清空技能。若新身体无法执行旧动作，记忆进入休眠；当获得兼容身体时可以恢复，也可能映射成相似动作。

## 第一版感知特征与动作

```text
感知特征：
  NearDryCrop
  NearFire
  NearBell
  NearInjuredVillager
  HoldingWater
  VillagersGathered

动作：
  FetchWater
  PourWater
  RingBell
  CarryObject
  ComfortVillager
  Flee
```

感知系统按策划优先级把特征归类成一个离散态势，避免直接组合出指数级状态。每次决策只评估当前身体支持的动作。动作倾向来自基础本能、强化学习得到的价值、性格修正和即时风险。第一版允许表格型强化学习，但不采用神经网络。冻结的态势、参数和奖励值见[首版模拟数据契约](SIMULATION_DATA_CONTRACT.md)。

## 三种教学方式

### 示范

玩家施放可见神迹，或可信村民在神兽可观察范围内完成动作。神兽记录当时最显著的上下文和结果。玩家可以引导它关注示范者，但一次示范仍只为对应动作建立较小的初始价值，不会立即锁定行为。

### 嘉许

神兽完成动作后的短时间内，玩家可以嘉许。嘉许作为明确的正奖励，强化“当时的上下文—最近动作”，不是永久提高一个全局技能。

### 制止

玩家在动作进行中制止，产生明确的负奖励，降低该上下文中的动作价值。制止不删除记忆，因此神兽可能在压力、不同地点或新身体下再次尝试。

## 强化学习方案

强化学习用于回答“神兽经历一个结果后，下一次会不会更愿意这样做”，而不是代替感知、寻路、动作动画或剧情规则。

首版采用策划可控的离散状态和动作表：

```text
Situation = 当前最显著的策划态势
Action    = 当前身体允许的候选动作
Q[S, A]   = 在该态势执行动作的预期价值
```

价值使用标准的时序差分方式更新：

```text
Q(s,a) ← Q(s,a) + α × [r + γ × max Q(s',a') - Q(s,a)]
```

- `α` 是较小且固定的学习率，避免一次奖励彻底覆盖历史。
- `γ` 首版保持较低，因为浇水、搬运、灭火等行为主要是短链结果。
- `r` 由玩家反馈、环境结果和性格倾向分项组成，并分别保存以便解释。
- 决策可使用低概率探索；探索只在安全候选动作中发生，并由 `GameplayRandom` 驱动。
- 相同 Tick、状态、随机种子与输入必须产生相同选择和价值更新。

首版优先使用 Contextual Bandit 或低折扣 Q-learning。只有真实玩法证明需要跨越多个步骤进行长期信用分配时，才考虑 Eligibility Trace、Option 或分层策略；不直接升级成深度强化学习。

### 奖励来源

| 来源 | 示例 | 作用 |
|---|---|---|
| 玩家反馈 | 嘉许、制止 | 表达玩家当下意图，权重受神兽信赖影响。 |
| 环境结果 | 作物恢复、火被扑灭、村民受伤 | 让神兽不依赖玩家每次手动评价。 |
| 性格奖励 | 好奇心满足、保护亲近村民 | 让不同神兽面对相同训练仍产生细微差异。 |
| 风险惩罚 | 受伤、路径失败、动作被阻挡 | 避免无效或危险动作无限重复。 |

环境奖励必须由有限的策划规则提供，不能简单把“资源数字增加”作为通用奖励，否则神兽容易找到违背玩家直觉的刷分行为。

### 安全边界

强化学习只能在规则允许的候选动作间选择：

- 身体能力和物体 Affordance 先过滤非法动作。
- 关键剧情对象、致命区域和不可恢复状态由硬约束保护。
- 连续失败动作进入冷却，避免原地循环。
- 奖励值、Q 值和单 Tick 更新幅度有固定上下限。
- 策划可查看每次选择的候选分数和最近一次更新原因。

这不是替玩家做决定，而是保证神兽可以犯有意义、可恢复、可说明的错误。

## 错误泛化

错误必须来自可解释的特征缺失，而不是随机犯蠢。例如：

1. 神兽看到玩家给枯萎麦田降雨。
2. 它学到“植物附近有水时应倒水”。
3. 因为还没学会区分“枯萎”和“正在举行葬礼的花圈”，它把水倒在花圈上。
4. 玩家制止后，它开始提高 `NearDryCrop` 特征的权重。

这种错误既是喜剧，也是玩家理解学习系统的窗口。

## 梦境解释

休息时，玩家可以看到神兽最近形成的简短因果图：

```text
看见干枯植物
  → 找到水
  → 倒水
  → 植物恢复
  → 得到嘉许
```

梦境只使用真实观察和动作，不捏造神兽没有经历过的理由。系统优先展示近期变化最大的 Q 值及其奖励来源，因此梦境同时是叙事、教学和强化学习调试器。

## 决策模型

概念上，每个候选动作得到一个可解释分数：

```text
动作分数 = 本能 + Q(态势, 动作) + 性格修正 - 即时风险
```

- 高好奇增加尝试低证据动作的机会。
- 高谨慎提高未知风险成本。
- 高共情提高救助村民和保护村庄的权重。
- 高自主性降低等待玩家在场的需求。

同分时使用固定顺序或 GameplayRandom，确保 Replay 可复现。

## 首版验收

- 神兽能通过两到三次示范学会给干旱作物浇水。
- 它至少可能产生一种玩家能够解释的错误泛化。
- 嘉许和制止能逐步改变行为，不是一次切换开关。
- 梦境展示的证据与实际事件一致。
- 状态快照恢复后，下一次选择与恢复前一致。
- 固定训练序列产生一致的 Q 表，且价值始终处于配置上限内。
- 非法动作、关键对象破坏和无休止失败循环不能通过探索出现。

## 延后内容

- 多身体换体和跨身体动作映射。
- 复杂语言指令、语音训练、生成式 AI 或深度强化学习。
- 遗传、繁殖和完整宠物生理模拟。
- 直接附身战斗和动作游戏式连招。
- 大规模神兽对战。
