# 村民、家庭与日常生活

## 设计原则

12 名村民不是完整人生模拟对象。每个人只拥有足以影响工作、观察、信仰传播和神兽关系的差异。所有差异必须能在行为或反馈中被玩家看见。

## 数值约定

以下属性使用整数，范围均为 `0..100`，神兽态度除外：

- `ObservationReliability`：亲眼观察转化为证据时的可靠度。
- `SocialInfluence`：证言传播给他人时的权重。
- `TraditionBias`：偏好既有仪式解释的程度。
- `FamiliarAttitude`：对神兽的初始态度，范围 `-100..100`。

属性不是能力检定，也不直接显示为百分比。玩家看到“谨慎”“受人尊敬”“迷信钟塔”等自然语言标签。

## 家庭关系的玩法意义

- 家庭成员在清晨和夜晚交换一条最高确信度观察。
- 午间中央广场允许跨家庭传播。
- 岑伯、眠婆的高影响力可以快速形成公共仪式。
- 澜姨、渡提供可靠反证，避免传统派永远垄断解释。
- 小禾、豆更愿意接近神兽，因此更容易观察其学习过程。

家庭不模拟婚姻、生育、财产继承或复杂好感网。

## 十分钟日程

一整个村庄日为现实时间 600 秒；Gameplay Pause 不推进日程。

| 现实时间 | 日程阶段 | 默认行为 |
|---|---|---|
| `0～60s` | 清晨 | 从家庭锚点出发；岑伯和小禾前往钟塔。 |
| `60～180s` | 首轮劳动 | 农夫检查麦田；水渠工检查水位；工坊成员搬运。 |
| `180～300s` | 危机处理 | 根据干旱和水闸任务重新分配工作；允许神兽观察示范。 |
| `300～390s` | 午间聚集 | 大多数村民前往广场，传播个人假说。 |
| `390～510s` | 第二轮劳动 | 按公共教义或实际需求选择敲钟、修渠、浇水。 |
| `510～570s` | 黄昏集会 | 形成第一版公共教义或公开怀疑。 |
| `570～600s` | 归家 | 家庭内部交换观察，写入当日记忆摘要。 |

## 工作系统

首版使用中心化 `VillageDirector` 产生任务，村民不运行通用 GOAP。

任务包含：

```text
TaskId
TaskKind
TargetEntity/Cell
Priority
RequiredRole
MaximumWorkers
ExpiresAtTick
```

任务优先级从高到低：生命危险 → 火灾 → 饮水 → 作物抢救 → 水渠修复 → 固定职责 → 社交与休息。相同优先级使用稳定 TaskId 和 VillagerId 排序，确保回放一致。

角色领取任务后运行简单状态机：

```text
Evaluate → Travel → Perform → Report → Return/ChooseNext
```

连续三次无法到达目标时报告失败并释放任务，不无限重试。

## 观察与交流

- 村民只有在工作、移动、聚集或明确观看时才能观察事件。
- 执行动作的村民对自身结果拥有最高可靠度。
- “引导注意”只影响神兽，不强制村民看向玩家目标。
- 听觉事件可以穿过建筑，视觉事件需要网格视线。
- 交流一次只传播一条当前最高优先级假说，避免午间瞬间同步全部知识。

## 可读反馈

聚焦村民时只显示四项：

- 当前要去做什么。
- 最近亲眼看见的关键事件。
- 当前最相信或最怀疑的一条因果。
- 对神兽的可读态度。

内部数值仅在开发诊断模式显示。玩家不需要查看 12 张属性表才能理解村庄。

## 验收

- 无玩家输入时，12 名村民能完成一个完整日程并安全归家。
- 至少三个家庭在午间前持有不同证据，而不是全村共享全知状态。
- 岑伯提出钟声教义时，澜姨可以因反证公开怀疑。
- 任意村民销毁或失活不会阻塞 Task 或传播队列。
- 相同输入和随机种子下，任务领取、路径目标和交流顺序一致。
