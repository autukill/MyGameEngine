# 核心循环与玩家动词

## 核心循环

```text
观察村庄
  → 判断谁正在期待什么
  → 施放或克制一次神迹
  → 世界产生可观察后果
  → 村民与神兽形成解释
  → 他们按自己的解释行动
  → 玩家面对新的机会与麻烦
```

玩家的主要乐趣来自“后果再次成为输入”。一次降雨不是完成任务后消失的特效，它会改变土地、水渠、村民信仰和神兽下一次可能采取的动作。

## 第一版玩家动词

| 动词 | 操作 | 设计作用 |
|---|---|---|
| 注视 | 指针悬停或选择 | 查看对象当前意图、最近观察与困惑，不暂停世界。 |
| 聚焦 | 点击村民、神兽或地点 | 让相机和简要信息围绕一个对象组织。 |
| 降雨 | 在有限圆形区域按住并释放 | 湿润土地、补水、灭火，也会破坏脆弱物品。 |
| 引导注意 | 从神兽拖向一个人物、对象或地点 | 暂时提高神兽对该目标的观察权重；它仍需自己理解看到的动作。 |
| 嘉许 | 在神兽完成动作后短时间内确认 | 强化最近的上下文—行动联系。 |
| 制止 | 在动作进行中打断 | 降低该上下文中的动作倾向，不等同于永久禁止。 |
| 等待 | 有意不回应 | 让村民的因果假说接受反证，也是玩家表达的一部分。 |

首版不提供直接编辑村民信仰、拖拽村民、任意改变地形或输入文字神谕。玩家必须通过世界中的可见行动表达。“引导注意”只决定神兽认真看什么，不直接指定它要学会什么。

## 三层节奏

### 数秒：神意循环

玩家观察一个即将发生的事件，决定施放、延迟或放弃神迹，并立即看到物理结果。反馈必须在一秒内开始出现。

### 数分钟：村庄循环

村民领取工作、移动、劳动、聚集、休息和举行仪式。信仰改变工作优先级，例如更频繁敲钟、避开神兽或在旱地留下供品。

### 约 30 分钟：岛屿章节

每座岛具有一个生存问题、一组地方习惯、一个神兽教学主题和一个不可完全兼得的选择。章节结束时生成地方神话，而不是仅显示通关星级。

## 资源关系

### 神意

“神意”是首版神迹预算，而不是道德分数。它缓慢恢复，集体仪式可以暂时加快恢复，但即使村民完全误解玩家，也必须保留最低自然恢复，避免玩家因拒绝利用迷信而失去行动能力。

首岛建议值只用于灰盒：

- 最大神意：3 格。
- 局部降雨：消耗 1 格。
- 自然恢复：约 45 秒 1 格。
- 真诚或迷信的集体仪式都能缩短恢复时间；系统不判断信仰是否“正确”。

### 信任与敬畏

不合并成善恶值。村民可以信任玩家却不敬畏，也可以恐惧玩家同时严格执行仪式。二者只作为群体行为条件，不作为唯一胜负资源。

### 神兽关系

不用单一亲密度代替教育。至少分开记录：

- 安全感：是否愿意在玩家附近尝试新行为。
- 信赖：奖励与制止是否具有较高学习权重。
- 自主性：没有明确示范时是否愿意行动。

## 失败与恢复

首岛不使用突然的 Game Over。严重问题进入可挽救状态：

- 作物先枯萎，再死亡。
- 村民先迁离危险区域，再考虑放弃村庄。
- 神兽犯错会产生后果，但不永久锁死谜题。
- 关键谜题物品损坏后由世界规则提供较慢的替代路径。

失败的价值是产生新的故事和代价，而不是要求玩家读取存档寻找唯一正确步骤。
