# 首个 10 分钟可玩流程

## 验证范围

这不是完整《鸣钟谷》，而是第一天的灰盒版本。它验证：指针观察、一次降雨、村民个人证据、午间传播、一次神兽搬运学习，以及玩家不响应时的恢复路径。

本版本结束于第一条公共教义形成或被公开质疑，不进入葬礼与结局壁画。

空间坐标以[《鸣钟谷》灰盒地图规格](MINGZHONG_VALLEY_MAP.md)为准；角色参数和模拟公式分别以[村民与日常生活](VILLAGERS_AND_DAILY_LIFE.md)及[首版模拟数据契约](SIMULATION_DATA_CONTRACT.md)为准。本文只负责安排事件，不重复定义底层规则。

## 初始状态

- 时间 `00:00`，固定 Tick 为 0。
- 神意 2/3，降雨消耗 1。
- 蓄水池 `Low`，水闸 `Blocked`，水渠 `Dry`。
- 三块田湿度：西 28、中 22、东 18；低于 20 开始枯萎。
- 巨石位于 `(31,11)`。
- 神兽在林地 `(42,16)`，Q 表全 0，信赖为 50/100。
- 钟声召雨 Prior：岑伯、眠婆 `+120`，其他村民 0。
- 所有村民从家庭锚点开始清晨日程。

## 时间线

### 00:00～01:00：看见村庄

| 时间 | 固定事件 | 可选玩家行为 |
|---|---|---|
| 00:00 | 镜头从中央广场缓慢移动到钟塔与西麦田之间。 | 可立即平移、缩放或聚焦人物。 |
| 00:15 | 木生到达西麦田，生成 `CropWithered` 前兆。 | 聚焦后看到“担心麦苗”。 |
| 00:35 | 岑伯敲晨钟，生成 `BellRang`。 | 玩家可以观察谁听见了钟。 |
| 00:42 | 东麦田进入枯萎，生成 `CropWithered`。 | 降雨神迹变为可用，但不强制弹窗暂停。 |

若玩家在钟后 8 秒内降雨，目击者获得第一份 `BellRang → RainStarted` 支持。若玩家等待，Cause 窗口自然超时，岑伯的 Prior 开始受到反证。

### 01:00～03:00：第一次神迹与可见后果

- 降雨命中麦田：湿度上升，约 5 秒后生成 `CropRecovered`。
- 降雨命中蓄水池：水位朝 `Ready` 增长，但水闸仍阻塞。
- 范围同时覆盖两者时，玩家能看见水位和作物两个后果。
- 没有降雨时，澜姨和阿穗开始用水井抢救西麦田，避免立即失败。

02:15，澜姨检查水闸并生成高显著性的任务标记；只有附近村民和聚焦玩家知道巨石阻塞。

### 03:00～05:00：神兽观察搬运

| 时间 | 世界行为 | 学习机会 |
|---|---|---|
| 03:00 | 砾和榆在工坊搬运两个空木箱。 | 玩家可把神兽的注意引向搬运者。 |
| 03:30 | 豆前往林地接近神兽，再朝工坊返回。 | 为神兽提供自然跟随路径，不直接控制它。 |
| 04:00 | 被引导的神兽获得 `CarryObject` 示范先验 `+800`。 | 没有引导时仍可因好奇观察，但概率较低。 |
| 04:20 | 水闸任务和巨石进入神兽可感知范围。 | 形成 `BlockedWaterGate` 态势并进行第一次选择。 |

合法结果：

- 搬动巨石：得到环境奖励，水闸开启。
- 搬走附近水桶：动作有效但未解决水闸；玩家可制止，灰陶会补充水桶。
- 暂时离开：180 Tick 后重新评估；砾和榆继续提供示范。

### 05:00～06:30：午间传播

村民在广场聚集，每人最多传播一条假说：

- 岑伯优先传播“钟声召雨”。
- 澜姨优先传播“水闸被巨石堵住”这一事实，并在钟响无雨时表达怀疑。
- 木生、阿穗根据是否亲眼看见作物恢复选择支持。
- 眠婆只有在假说达到猜测阈值后才提出仪式，不凭剧本直接宣布教义。

此时首次显示信仰证据面板，内容必须来自实际发生的观察。

### 06:30～08:30：第二次可控对照

06:45，岑伯因旱情提出再次敲钟。07:00 生成第二次 `BellRang`。

玩家可以：

- 立即降雨：强化钟声假说。
- 等待窗口结束，再无钟降雨：制造反证和替代证据。
- 只给蓄水池降雨：村民可能听到雨却看不到麦田恢复。
- 完全不降雨：村民依靠水闸或水井，钟声假说下降。

游戏不标记“正确选项”。所有选择都必须允许日程继续。

### 08:30～10:00：形成第一日结论

- 如果神兽尚未移开巨石，砾和榆在 08:30 开始共同清障，90 秒完成。
- 如果神兽成功，村民产生 `FamiliarActed → GateOpened` 的真实证据。
- 如果至少一条假说满足公共教义条件，黄昏集会采用它安排次日工作。
- 如果没有假说达到条件，村庄明确进入“意见未决”，不是静默失败。

10:00 显示第一日摘要：

```text
今天村民亲眼看见了什么？
他们开始相信什么？
谁公开怀疑？
神兽从哪次行动中改变最大？
```

## 主要分支

| 分支 | 当日结果 | 后续钩子 |
|---|---|---|
| 两次钟后降雨 | 钟声教义很可能建立。 | 次日村民优先维护和频繁敲钟。 |
| 一次配合、一次反证 | 村庄分成传统派和怀疑派。 | 葬礼阶段冲突更明显。 |
| 无钟时降雨 | “神回应枯萎作物”可能取代钟声解释。 | 农夫影响提高，钟守失去权威。 |
| 完全不降雨 | 水渠和神兽成为主要解释。 | 神意保留，但部分作物进入严重枯萎。 |
| 神兽搬对巨石 | 搬运 Q 值提高，村民更信任神兽。 | 后续可能主动搬运其他阻挡。 |
| 神兽搬错水桶 | 出现可解释错误，玩家有纠正机会。 | 神兽梦境显示“水边物体”的混淆。 |

## 防锁死与恢复

- 玩家没有降雨：水井能维持至少一块田，关卡继续。
- 玩家把两次神意都用错位置：自然恢复保证 45 秒后重新获得 1 格。
- 神兽拒绝搬运：砾和榆最终人工清障，但玩家失去一部分神兽学习证据。
- 水桶被错误搬走：灰陶 20 秒后制作替代品。
- 村民路径失败：任务释放并回到最近安全锚点。
- 没有形成公共信仰：生成“意见未决”状态，第二日继续提供证据。
- 玩家完全不操作：村民能靠水井和人工清障进入第二日，但东麦田严重枯萎。

恢复路径只避免技术性锁死，不抹除玩家造成的资源和社会后果。

## 首次玩测记录

每次测试保存 Replay Bundle、状态 Hash 轨迹和一份低频诊断日志：

- 玩家第一次降雨 Tick 和范围中心。
- 每次钟声的观察者和因果窗口结果。
- 午间传播的发言顺序与分数变化。
- 神兽每次候选动作、探索判定、奖励和 Q 值变化。
- 10 分钟时三块田、水闸、公共教义和神兽最高 Q 项。

观察员另外记录：玩家是否主动查看证据、是否理解神兽为何搬错、是否觉得第二次钟声是有意义的选择。

## Go / No-Go

可以进入完整 30 分钟切片的最低条件：

- 至少 4/5 名盲测玩家能解释一条信仰的实际证据。
- 至少 3/5 名玩家认为等待第二次钟声的结果也是有效选择。
- 至少 4/5 名玩家能把神兽一次行为与示范或奖励联系起来。
- 五次流程中出现至少两种不同的村庄结论，且都能继续游戏。
- 所有固定输入回放在 10 分钟内没有状态 Hash 分叉。

未达到时优先调整反馈、时间窗、空间布局和事件安排，不增加新神迹、新身体或正式美术。
