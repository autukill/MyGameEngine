《神意难测 / The God They Made》——《鸣钟谷》外部盲测包

本构建用于未经规则讲解的外部测试，不是正式发行版。

开始：
1. 解压整个压缩包，不能只复制 exe。
2. 双击 Start-Playtest.cmd。
3. 输入主持人分配的测试编号，例如 tester-01。
4. 正常游玩；看到章节结局壁画后按 ESC 退出。
5. 将新生成的 PlaytestData 文件夹完整交给主持人。

基本操作：
- WASD 或方向键：移动镜头。
- 鼠标滚轮：缩放。
- 在世界中按下并释放鼠标左键：对最终格子表达神意。
- Q：嘉许神兽最近的行为。
- E：制止神兽最近的行为。
- ESC：退出并保存本次会话报告。

请不要在测试前阅读设计文档、源代码或他人的测试答案。没有“必须照做”的唯一路线；等待和不回应也是允许的。

若窗口意外关闭或程序报错，请保留 PlaytestData 文件夹，并把发生问题前的操作和错误画面告诉主持人。不要用相同测试编号重新覆盖；程序会拒绝覆盖已有证据。
